# マルシェ 出店申し込み一覧 Webアプリ

Googleスプレッドシート（申し込み受付リスト）を見やすく・共有しやすい形で表示するWebアプリです。

## 主な機能
- **ワンボタン更新（「最新データに更新」）**: ボタンを押すと Googleスプレッドシートから最新データを即座に取得して画面を更新します。
- **共有モード（連絡先を隠す）**: デフォルトでメールアドレス・電話番号を非表示にし、画面共有やリンク共有時にも配慮しています。
- **共有テキストをコピー**: 申し込み一覧をLINEやSlack、メールで送りやすいテキスト形式でクリップボードにコピーできます。
- **検索・絞り込み・表示切替**: キーワード検索、電源あり/備品あり/質問ありのフィルター、所属会別フィルター、カード表示/一覧表表示を切り替えられます。
- **GitHub 継続保存・自動デプロイ**:
  - `scripts/sync_and_push.sh` を実行すると、最新データを `data/applications.json` / `data/applications.csv` に保存し、GitHub へ自動コミット＆プッシュします。
  - GitHub Actions（`.github/workflows/sync-and-pages.yml`）により、毎日自動でスナップショットを保存＆GitHub Pagesへ公開します。

## ローカルでの起動・GitHubプッシュ方法

```bash
# ローカルでWebアプリを確認
python3 -m http.server 8080

# スプレッドシートの最新データを取得してGitHubへプッシュ
./scripts/sync_and_push.sh
```
